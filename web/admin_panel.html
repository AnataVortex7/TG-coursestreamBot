📖 Folder कसे काम करतात?
• Folder delete केल्यावर files delete होत नाहीत — त्या Ungrouped म्हणून दिसतात.
• Range म्हणजे files चा sequential number (sort_order) — e.g. 1–26 = 1 ते 26 वी file.
• एका folder मध्ये multiple ranges असू शकतात — e.g. 1–10 आणि 45–50.
• Ranges overlap नसाव्यात.
